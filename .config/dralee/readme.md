## dralee customer tools and configs
### weather
the weather tool for waybar & hyprland

#### use the weather
* for help
```bash
$ ~/.config/xxx/weather/weather.sh -h
```
* for waybar
```bash
$ ~/.config/xxx/weather/weather.sh -w
```
* for hyprlock
```bash
~/.config/xxx/weather/weather.sh -i temp,...
```
